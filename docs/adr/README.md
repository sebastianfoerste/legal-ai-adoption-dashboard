# Architecture decision records

Numbered, never renumbered. Each records the status, the context, the decision and its
consequences. `Proposed` means waiting for the owner; nothing in it is built.

| ADR | Status | Decision |
| --- | --- | --- |
| [0001](0001-charts.md) | Accepted | Charts are hand-rolled SVG Server Components with a hidden data table |
| [0002](0002-navigation.md) | Accepted | A grouped sidebar from the `lg` breakpoint, plus route states |
| [0003](0003-dark-mode.md) | Proposed | Dark mode through semantic tokens, only after every token passes AA in both themes |
| [0004](0004-exports.md) | Proposed | Leadership PDF through a print stylesheet; PPTX deferred |
| [0005](0005-saved-views.md) | Proposed | Saved views as URL query strings with committed presets |
